CAN 주행 로그 분석

이 주행에 급제동이 있었나요?

차량 센서 기록(CAN) 파일을 올리면, 직접 학습한 머신러닝 모델이 급감속·급정지가 있었을 확률을 알려줍니다.

사용 방법

  1. 파일 고르기 예시 주행을 누르거나, 내 CAN JSON 파일을 올립니다.
  2. 분석 기다리기 서버가 속도와 브레이크 기록에서 제동 세기를 계산합니다. 보통 몇 초 걸립니다.
  3. 결과 보기 급제동 확률과 함께, 가장 세게 감속한 순간을 그래프에서 확인합니다.

이 모델에 대해

  • 2분 안팎의 주행 클립 하나에 급감속 또는 급정지가 있었는지를 판정합니다. 사고 확률을 예측하는 모델이 아닙니다.
  • 테스트 도로에서 수집한 클립 323개로 학습하고 평가했습니다. 실제 도로 주행에서의 정확도는 검증되지 않았습니다.
  • 급정지는 급감속보다 잘 놓치는 편입니다.
